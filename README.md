# Measures Converter

Hands-on Assignment 1 for MSCS 533: Software Engineering Labs.

## Description

This Flutter application converts common metric and imperial measurements. It supports length conversions among meters, kilometers, miles, and feet, and weight conversions between kilograms and pounds.

## Features

- Numeric value input
- From and To unit selection
- Metric and imperial conversions
- Input validation
- User-friendly conversion result
- Commented Dart source code following common Flutter/Dart practices

## Example

Input: `100`

From: `meters`

To: `feet`

Output: `100.0 meters are 328.084 feet`

## Run the Project

1. Install Flutter and configure an Android/iOS development environment.
2. Open the project in Android Studio or Visual Studio Code.
3. Run `flutter pub get`.
4. Start an emulator/simulator or connect a physical device.
5. Run `flutter run`.
